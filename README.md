# 🎲 Alfihen RPG Hub

![Status do Projeto](https://img.shields.io/badge/Status-Em%20Desenvolvimento-darkgreen?style=for-the-badge)
![Licença](https://img.shields.io/badge/Licen%C3%A7a-MIT-gold?style=for-the-badge)

**Alfihen** é uma plataforma web premium e imersiva projetada para conectar Mestres e Jogadores de RPG de mesa (Tabletop RPGs). Com uma interface sombria, mística e sofisticada, o hub permite a organização de campanhas, busca de mesas e gerenciamento de sistemas clássicos e modernos em um único lugar.

---

## 🔮 Funcionalidades Principais

*   **Hub de Campanhas:** Organização visual de mesas ativas divididas por sistemas.
*   **Matchmaking de RPG:** Sistema eficiente para jogadores encontrarem narradores e mesas disponíveis.
*   **Interface Imersiva:** Design escuro (obsidian black) com detalhes em verde-esmeralda e dourado, projetado para evocar a atmosfera de uma biblioteca antiga de feitiçaria.
*   **Painel do Mestre (Ferramentas):** Atalhos rápidos para utilitários de auxílio ao mestre durante as sessões.
